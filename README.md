# reformthenorth.com

Static site for [reformthenorth.com](https://reformthenorth.com).

## Go live (Cloudflare Pages)

1. In Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**.
2. Select `bpaiement/reformthenorth-com`.
3. Build command: empty. Output directory: `/`.
4. Add custom domain `reformthenorth.com` (and `www` if you use it).

The `CNAME` file is for GitHub Pages. If you host on Cloudflare Pages you can ignore it.
